# SrokYerng Booking Frontend

Vue frontend for the SrokYerng Booking accommodation reservation platform.

## Tech Stack

- Vue 3
- Vite
- Vue Router
- Pinia
- Axios

## Setup

See `docs/setup-guide.md`.

## Run

Development server:

```bash
npm run dev
```

Production build:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```

# Frontend Docs

Use this folder for team-facing frontend decisions and workflows.

## Files

- `setup-guide.md`: local setup, environment variables, and run/build commands
- `frontend-rules.md`: coding rules for structure, routing, API calls, stores, and styling
- `module-ownership.md`: module ownership, scaffold policy, and team responsibilities

Keep docs concise. If a rule affects multiple teammates, document it here instead of only explaining it in chat.
